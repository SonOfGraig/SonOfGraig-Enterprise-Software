# 04 — Gradient System

Six **functional** gradients. If a gradient does not have a job, it does not exist.

| Name | Definition | Usage |
|---|---|---|
| Brand Primary | `135deg, #0B9EDE → #38BDF8` | Hero section headers, primary card accents, marketing moments |
| Premium Accent | `135deg, #F97316 → #FBBF24` | Pricing cards, upgrade CTAs, Enterprise tier callouts |
| Brand Span | `90deg, #0B9EDE → #F97316` | Metric card top border accent, loading bars, progress fills |
| Surface Depth | `135deg, #070810 → #161B25` | Dark card backgrounds, elevated panel fills |
| Blue Glow | `radial, rgba(11,158,222,.18) → transparent` | Active component background, focus zone highlight |
| Surface Fade | `180deg, var(--sg-surface) → var(--sg-bg)` | Content scroll fade, list boundary fade |

## Don't

- Decorative-only gradients (no purpose).
- Gradients on text body. Headings only — and only Brand Primary.
- Three or more colour stops. Two-stop gradients only.

→ Source: [`source-docs/design-system-v3.md`](source-docs/design-system-v3.md), Section 5.
